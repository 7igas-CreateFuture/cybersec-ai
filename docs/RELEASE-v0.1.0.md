# v0.1.0 — Phase 1 基线版

CyberSec AI 首个私有开发基线。复用现有 Local AI，提供独立安全模型配置和可重复评估，保留原文件助手。

## 包含

- 原生聊天 UI、双模型选择、流式响应、取消与 SQLite 历史。
- 本地 Ollama 路由、独立 system/options、GPU 与最终 token 统计。
- 合成安全样例、真实基线输出、候选对照与明确的失败记录。
- 配置、测试、安装前提及作者机器路径清理。

## 验证范围

原部署已完成 25 项单元/合成反例、8 项隔离 HTTP 和 9 项原网址验收；Python 启动入口另外 5 项分支检查通过。原有模型和聊天完整保留，仅新增两条标记验收对话。仓库整理后的检查另见 `evidence/release/`，不要把历史验收自动当成新 checkout 已测试。

## 运行前提与限制

Python 3.10+、本地 Ollama、已有 company-local 模型；PDF/XLSX 依赖见 requirements.txt。权重、聊天库和凭据不包含在发布内容中。此前机器的运行路径已从发布代码移除，但尚未完成全新机器安装验证。

候选 prompt 不部署；没有训练、RAG 或 Agent，没有证据证明安全分析能力整体提升。PowerShell 部分额外行为验证此前受执行环境限制，直接 Python 入口作为明确可用的启动方式。相同 profile 版本不能鉴别所有源码版本，切换 checkout 需核对实际进程路径。

源码尚未选定整体开源许可证；当前仅私有管理。版本 0.1.0 表示早期开发基线，不是成熟安全产品或 v1.0 稳定接口承诺。
