# v0.1.0 — Phase 1 基线版

CyberSec AI 首个开发基线，最初私有发布，随后于 2026-11-02 按项目负责人要求公开仓库。复用现有 Local AI，提供独立安全模型配置和可重复评估，保留原文件助手。

## 包含

- 原生聊天 UI、双模型选择、流式响应、取消与 SQLite 历史。
- 本地 Ollama 路由、独立 system/options、GPU 与最终 token 统计。
- 合成安全样例、真实基线输出、候选对照与明确的失败记录。
- 配置、测试、安装前提及作者机器路径清理。

## 验证范围

原部署已完成 25 项单元/合成反例、8 项隔离 HTTP 和 9 项原网址验收；Python 启动入口另外 5 项分支检查通过。原有模型和聊天完整保留，仅新增两条标记验收对话。仓库整理后的检查另见 `evidence/release/`，不要把历史验收自动当成新 checkout 已测试。

本次发布目录重新通过 25 项单元/反例、5 项 Python 启动分支及 8 项真实隔离 HTTP 检查。从 Git 导出的独立副本再次通过 25 + 5 项检查，并成功启动自己的进程，验证健康版本、HTML/token、JS/CSS 和独立空白历史。该启动检查没有调用模型，也没有使用真实聊天库。验证使用本机已有 Python、JDK 和 Ollama，不声称已经完成全新机器安装。

DS Pro 独立复核了发布范围，要求补上干净 Git 副本验证、身份/路径扫描和明确的解释器/许可边界；上述检查已落实。代码的开源许可没有被擅自指定。

## 运行前提与限制

Python 3.10+、本地 Ollama、已有 company-local 模型；PDF/XLSX 依赖见 requirements.txt。权重、聊天库和凭据不包含在发布内容中。此前机器的运行路径已从发布代码移除，但尚未完成全新机器安装验证。

候选 prompt 不部署；没有训练、RAG 或 Agent，没有证据证明安全分析能力整体提升。PowerShell 部分额外行为验证此前受执行环境限制，直接 Python 入口作为明确可用的启动方式。相同 profile 版本不能鉴别所有源码版本，切换 checkout 需核对实际进程路径。

源码尚未选定整体开源许可证；仓库现可公开浏览。版本 0.1.0 表示早期开发基线，不是成熟安全产品或 v1.0 稳定接口承诺。已发布的 v0.1.0 标签和下载包保持原样，其中的私有状态说明反映首次发布时的状态；最新可见性以仓库设置和 main 分支说明为准。
